# Promo Menupage Automation Releases

Public release-only repository for Promo Menupage Automation.

This repository intentionally contains **no internal Team LINE configuration and no workstation config**.

Public release assets:

- `PromoMenupageAutomation_CloudInstall_<version>.zip` — fresh machine installer.
- `PromoMenupageAutomation_Update_<version>.zip` — updater for existing installs.
- `com.amarintv.promo.menupagebuilder_<version>.ccx` — Adobe UXP plugin package.
- `stable.json` — update manifest consumed by installed clients.

Source development remains in the private repository `boyfk8/promo-menupage-automation`.
